# /idea — журнал идей

Вход: $ARGUMENTS

1. Идея — желаемое добавление/изменение. Поломка → `/bug`, пустая клетка ресурса → `/kit`.
2. Прочитай `mini-sim/JOURNAL_IDEAS.md`. Похожая идея есть → дополни её, не заводи дубль.
3. Слова владельца записывай как его слова (с датой/временем, если есть). Собственные выводы помечай «набросок, не решение». Не выдумывай выборы за владельца: открытые развилки перечисли пунктом «Не выбрано, код не писать».
4. Новый номер = максимальный IDEA-NNN + 1, в конец файла.

```markdown
## IDEA-NNN — <название>

- **Мини-игры:** <…>.
- **Версия:** <есть ли что-то на текущей линии; «нет», если нет>.
- **Категория:** <из 11 категорий JOURNAL_KIT.md>.
- **Статус:** `IDEA`.
- **Суть:** <…>.
- **Дальше / Не выбрано:** <…>.
```

5. `TAKEN` ставь только когда работа реально начата на `main` и есть WORK LOCK — со ссылкой на Issue.
6. Покажи запись владельцу.
