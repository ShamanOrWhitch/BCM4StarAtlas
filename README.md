# BCM4StarAtlas

Best Crew Missions 4 Star Atlas — симулятор / конфигуратор сбора команды и миссий.

Репозиторий: исходники приложения (экипаж, корабли, картограф, архив).

## Что внутри

- `src/routes/crew.tsx` — сбор команды
- `src/routes/ships.tsx` — корабли
- `src/routes/index.tsx` — главная / станция
- `src/data/` — данные экипажа, кораблей, систем
- `public/portraits/` — портреты рас

## Запуск

```bash
npm install
npm run dev
```

## Медиа кораблей

Галереи грузятся с официального CDN Star Atlas (`storage.googleapis.com/nft-assets`),
как в Galactic Marketplace / [Galaxy API](https://galaxy.staratlas.com/nfts).
Локальная папка `public/ships/` не нужна.

## Mini Space Simulation — playable test

Папка `mini-sim/` содержит первую реально запускаемую тестовую оболочку 6DOF-симулятора.

WordPress shortcode:

```
[bcm_mini_sim]
```

После нажатия **ИГРАТЬ** запускается пилотный тест:

- полёт с инерцией по шести степеням свободы;
- мышь — обзор, Q/E — крен;
- W/S — тяга вперёд/назад;
- A/D — страйф;
- Space/Ctrl — подъём/спуск;
- F — щит ON/OFF;
- тестовый коридор и дверь;
- процедурная оболочка из секторов;
- портал оставлен как заготовка для будущих переходов между участками.

Это именно **тест управления и оболочки**, а не финальная игровая карта. Следующий логичный слой — нормальные модульные комнаты/секции, столкновения, условия выхода и переход в следующий игровой режим.
