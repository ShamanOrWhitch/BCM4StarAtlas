# BCM4SA — Warp visual sketches

Шесть самостоятельных фоновых SVG-скетчей для сравнения вариантов визуального перехода между seed в Warp.

## Варианты

- [01 Star Tunnel](./01-star-tunnel.svg) — радиальные световые линии и перспектива гиперпространства.
- [02 Particle Seed](./02-particle-seed.svg) — облако частиц и осколков, подходящее для рассыпания/сборки.
- [03 Energy Waves](./03-energy-waves.svg) — концентрические энергетические волны.
- [04 Scan Transition](./04-scan-transition.svg) — горизонтальные полосы сканирования и световые проходы.
- [05 Deep Parallax](./05-deep-parallax.svg) — планеты, звёзды и глубина нескольких слоёв.
- [06 Portal Shift](./06-portal-shift.svg) — световой пространственный портал.

Все рисунки — оригинальные векторные эскизы, без людей, лиц, персонажей, радаров, HUD и кабинных панелей. Они размещены отдельно и **не подключены** к игровому Warp.

Позднее можно сравнить их с AI-концепт-листом из чата. Эти SVG — лёгкие фоновые референсы, а не финальные игровые текстуры и не реализация анимации.

Предлагаемый ритм будущего перехода: 3 секунды анимации + 4,5 секунды покоя. Интеграцию выполнять отдельной задачей и останавливать по реальному событию прибытия Warp.
