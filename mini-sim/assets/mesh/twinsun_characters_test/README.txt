spherical_robot_blockout.glb — круглый робот; hooded_traveller_blockout.glb — персонаж в капюшоне; one_eye_robot_blockout.glb — одноглазый робот. Файлы для проверки силуэтов, не готовые персонажи и не точные копии скетчей. Части пересекаются в местах соединения. Внутри отдельные меши, но нет скелета, скиннинга, анимации, UV и текстур. Используется цвет вершин. Коллизий и игровых настроек нет. Количество треугольников и деталей — manifest.json. Blender: File > Import > glTF 2.0. Не протестировано в Blender, Three.js и на Android. PNG изображения приблизительные, возможны ложные наложения из-за способа отрисовки.
