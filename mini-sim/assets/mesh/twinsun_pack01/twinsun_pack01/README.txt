TWINSUN — ПРОТОТИПНЫЙ НАБОР 01: КАМНИ И КРИСТАЛЛЫ

Состав:
assembled/ — 4 собранных варианта одного камня: бирюзовый, фиолетовый, оранжевый и зелёный кристалл. Геометрия одинаковая, различаются только цвета.
parts/ — отдельные камни, отдельные кристаллы в четырёх цветах, а также две готовые группы: камни и группа кристаллов.
manifest.json — число треугольников в каждом файле.

В Blender: File > Import > glTF 2.0, выбрать GLB. Части сохраняют общую систему координат исходной композиции: если импортировать нужные детали в одну сцену без смещения, они должны совпасть. Поэтому отдельная деталь не обязательно находится в центре координат. Цвета записаны в вершинах, PNG-текстур и UV нет. Это упрощённые прототипы, не окончательные модели по шести листам. Кристаллы не излучают реальный свет.

В Three.js: формат GLB требует подходящего GLTFLoader, совместимого с r128. Файлы не проверялись в Blender, Three.js или на Android. Проверка осей, цветов, производительности и корректного отображения в вашем проекте обязательна. При массовом размещении учитывайте количество мешей и draw calls, а не только полигоны.

Модель создана процедурно по мотивам пользовательского референса. Без сторонних ресурсов LBA.
