  prow_plates   две тёмные полированные мандибулы над буровой головой
  visor_ring    янтарное кольцо-визор (12 сегментов) + «печь» внутри головы
  crusher       барабан-измельчитель с зубцами, бандажами и резцами
                (узел стоит на оси головы и вращается вокруг X)
  jaws          неподвижные клыки-отбойники вокруг барабана
  hangar        два ангарных проёма снизу: тёплый свет, решётчатые полы, мостки
  gantry        наружные мостки, поручни, кабельные лотки
  engines       маршевый блок из восьми сопел
  thrusters     диски тяги на срезах сопел (отдельный узел)
  greebles      люки, вентиляция, короба, навески, ангарные табло
  lights        синие носовые прожекторы, янтарные рабочие огни, маркеры
  arm_0r…arm_2l шесть «рук» в три яруса: шарнир, плечевая связка с золотыми
                тягами, плоский бак-слэб с вентиляционными рёбрами,
                клешня-измельчитель на конце
  fins_l/fins_r по четыре плоских ребра-радиатора на корме
  pylon_0…3     стыковочные пилоны: в стыковке ступни на Y = 0

ГЕОМЕТРИЯ И ПРОВЕРКИ
  * 440.5 × 121.0 × 262.0 м — внутри паспортных 443 × 262 × 121; проверка идёт
    дважды: по деталям в create.py и по вершинам записанного GLB с учётом
    поворотов узлов; при выходе за габарит сборка падает с ошибкой;
  * 29 крупных деталей проверены на пересечение — 0 (клыки охватывают барабан
    по замыслу и в проверке не считаются пересечением);
  * ступни пилонов ровно на Y = 0, в полёте пилоны уходят в корпус;
  * в убранном положении руки уходят внутрь на 14 м, ширина остаётся 262 м;
  * запечённое затенение в цветах вершин (unlit), своих текстур нет;
  * материалы (6): сильвер-броня, корпус, тёмный полированный металл, визор,
    тяга, огни.

РЕЖИМЫ (modes.json и контроллер)
  docked   пилоны выпущены (Y = 0), руки развёрнуты, визор 35 %, прожекторы 60 %
  mining   пилоны убраны, барабан 1.2× (2.4 рад/с), визор и прожекторы на 100 %
  transit  руки задвинуты на 14 м, тяга 55 %, визор 30 %
  warp     руки задвинуты, тяга 100 %, барабан стоит

ПОДКЛЮЧЕНИЕ (Three.js r128, ничего не патчится)
  new THREE.GLTFLoader().load('armstrong_imp.glb', (g) => {
    scene.add(g.scene);
    const rig = createImpControls(g.scene);   // imp_controls.js
    rig.setMode('docked');
    createImpPanel(rig);                      // imp_panel.js, необязательно
    // в кадре: rig.update(t, camera) каждый кадр
  });

  API
    setMode('docked'|'mining'|'transit'|'warp') / getMode() / getModes()
    setArms(0..1)          — вручную задвинуть/развернуть руки (режим → manual)
    setPylons(0..1)        — стыковочные пилоны
    setCrusherSpeed(0..3)  — барабан-измельчитель (1.0 = 2.4 рад/с)
    setThrust(0..1)        — тяга, управляет дисками сопел
    setVisor(0..1)         — янтарное кольцо буровой головы
    setFloods(0..1)        — прожекторы и рабочие огни
    setEngines(bool)       — главный выключатель дюз
    setShaderMode(bool)    — CPU (unlit, по умолчанию) ⇄ GPU (MeshPhongMaterial)
    update(time, camera) / getState() / dispose()

ДВА ПУТИ ОТРИСОВКИ
  CPU (по умолчанию)  MeshBasicMaterial + vertexColors: 26 draw calls, шейдеров
                      нет, затенение запечено в вершины. Основной путь для
                      слабого Android, геометрия в кадре не пересчитывается.
  SHADER (опция)      MeshPhongMaterial с теми же vertexColors: настоящий свет
                      сцены (ambient + 2 directional), дороже на слабых GPU.
  Смена пути — переключение материала, GLB не пересобирается.

МАСШТАБ И ЦВЕТ
  Единицы — метры, Y вверх, нос в −X, дюзы в +X. Ширина 262 м — по законцовкам
  шести рук (проверено по вершинам, а не по AABB), высота 121 м — по гребню носа.
  Палитра: сильвер-броня корпуса, тёмный полированный металл мандибул и машинерии,
  красно-оранжевые накладки и транец, золото-янтарная буровая голова (визор,
  «печь», бандажи барабана, гидравлика рук), синие прожекторы и маркеры.
  Серебро здесь своё — это не «хамелеон» Rainbow Chi.
