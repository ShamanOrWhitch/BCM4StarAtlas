  imp_panel.js           панель управления (чистый DOM, без зависимостей)
  imp_demo.html          автономная демка: three r128 + GLTFLoader + GLB внутри одного файла
  build_demo.py          сборка демки из imp_tap.glb (base64)
  imp_load_check.js      прогон GLB и контроллера через НАСТОЯЩИЙ GLTFLoader r128 (Node)
  armstrong-imp-tap.test.mjs  4 статических теста (node --test)
  create.py              генератор геометрии (numpy, свой GLB-writer)
  glb_writer.py          минимальный экспортёр glTF 2.0 (боксы, цилиндры, фасетки)
  render_preview.py      программный растеризатор без GPU → preview.jpg
  modes.json             режимы и параметры шарниров (для игры)
  preview.jpg            6 ракурсов: посадка, нос, полёт, сверху, борт, корма

УЗЛЫ МОДЕЛИ (имена в GLB)
  hull           тёмная несущая рама: шпангоуты, рёбра, брызговики шарниров
  shell          оранжево-песочный карапас: фасетные скосы + тёмный позвоночник
  armor          плиты палубы, бортовые накладки, поды-«крылья», бровь-свес
  machinery      трубопроводы, насосные блоки, радиаторные гребёнки, трапы
  drill_mount    тёмный силовой блок буров, щёки, кожухи над барабанами
  drills         ТРИ барабана с зубцами, бандажами и резцами — ВРАЩАЕТСЯ вокруг X
  engines        4 + 2 раструба дюз (батарея 3+3 в 2 ряда), решётки, бленкеры
  thrusters      диски тяги на срезах дюз — отдельный узел, гаснут/зажигаются
  lights         посадочные прожекторы (синие), маркеры, подсветка буров
  leg_0 … leg_5  шесть лап; ноль узла — шарнир бедра, ступни на Y = 0

ГЕОМЕТРИЯ И ПРОВЕРКИ
  * всё внутри официального габарита: 47.8 × 19.0 × 48.5 м (проверка в create.py
    падает с ошибкой, если хоть одна деталь выходит за пределы);
  * 41 крупная деталь проверена на пересечение AABB — 0 пересечений, в том числе
    в сложенной позе лап (складка 96°, приближение по AABB);
  * ступни лап стоят ровно на Y = 0, в полёте лапы уходят под днище и не выходят
    за габарит по ширине;
  * запечённое затенение в цветах вершин (unlit), текстур нет — свои цвета только.

РЕЖИМЫ (modes.json и контроллер)
  landed   лапы выпущены, ступни на земле, барабаны стоят, прожекторы горят
  mining   лапы выпущены, барабаны 1.0× (6 рад/с), корпус мелко вибрирует
  flight   лапы убраны (складка 96°), барабаны 0.35×, тяга 100 %
  transit  лапы убраны, барабаны стоят, тяга 50 %

ПОДКЛЮЧЕНИЕ (Three.js r128, ничего не патчится)
  const loader = new THREE.GLTFLoader();
  loader.load('imp_tap.glb', (g) => {
    scene.add(g.scene);
    const rig = createImpTapControls(g.scene);   // imp_controls.js
    rig.setMode('landed');
    createImpTapPanel(rig);                      // imp_panel.js, необязательно
    // в кадре: rig.update(t, camera) каждый кадр
  });

  API контроллера
    setMode('landed'|'mining'|'flight'|'transit') / getMode() / getModes()
    setLegs(0..1)          — вручную убрать/выпустить лапы (режим → 'manual')
    setDrillSpeed(0..2.5)  — скорость барабанов (1.0 = 6 рад/с)
    setThrust(0..1)        — тяга, управляет дисками thrusters
    setLights(0..1)        — посадочные прожекторы (пульсация на CPU)
    setEngines(bool)       — главный выключатель дюз
    setShaderMode(bool)    — CPU (unlit, по умолчанию) ⇄ GPU (MeshPhongMaterial)
    update(time, camera)   — один вызов на кадр; getState() — текущее состояние
    dispose()              — освободить материалы

ДВА ПУТИ ОТРИСОВКИ
  CPU (по умолчанию)  MeshBasicMaterial + vertexColors: 15 draw calls, шейдеров нет,
                      цвет и затенение запечены в вершины. Основной путь для слабого
                      Android. Ни одного пересчёта геометрии в кадре.
  SHADER (опция)      MeshPhongMaterial с теми же vertexColors: настоящий свет сцены
                      (ambient + 2 directional), дороже на слабых GPU.
  Смена пути — переключение материала, GLB не пересобирается.

МАСШТАБ И ЦВЕТ
  Единицы — метры, Y — вверх, нос смотрит в −X, дюзы в +X. Ширина 48.5 м — по
  внешним подам-«крыльям», высота 19 м — по гребню позвоночника палубы.
  Палитра: оранжево-песочная броня (0.62/0.33/0.10 и светлее), тёмная сталь рамы,
  ржавые бандажи буров, фиолетовое свечение дюз (0.66/0.34/1.0), синие прожекторы,
  красные кормовые маркеры. Атмосфера — индустриальный шахтёрский борт, без бликов
  «серебра» (серебро — отличительная черта Rainbow Chi).
