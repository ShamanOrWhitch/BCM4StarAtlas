Pearce F4 (PF4) — 3D-корабль для Three.js r128  ·  56.0 × 9.4 × 19.3 м
==============================================
Что в архиве
------------
  pearce_f4.glb              — модель (vertex colors, без текстур)
  pearce_f4_controls.js      — контроллер: режимы, шасси, орудия, створки,
                               трап аппарели (полотно + выдвижная ступень), тяга
  pearce_f4_panel.js         — панель управления (чистый DOM)
  pearce_f4_demo.html        — автономная демка: three r128 + GLTFLoader + GLB
                               в base64, работает без сети
  modes.json                 — режимы и параметры приводов
  preview.jpg                — 8 ракурсов (CPU-растеризация, без GPU)
  hero.jpg                   — один парадный кадр
  NOTES.txt                  — паспорт корабля, числа, история правок
  create.py + glb_writer.py  — генератор геометрии (Python/NumPy → GLB)
  render_preview.py          — программный рендер без GPU
  hole_check.py, hole_base.json — автопроверка сквозных дыр обшивки
  build_demo.py              — сборка демки
  pearce_f4_load_check.js    — прогон через настоящий GLTFLoader r128
  pearce-f4.test.mjs         — 9 тестов (node --test)

Как подключить
--------------
  1) Положить pearce_f4.glb и pearce_f4_controls.js рядом с остальными кораблями.
  2) После загрузки GLB:
       var rig = createPearceF4Controls(gltf.scene);
       rig.setMode('pad');            // pad | flight | hunt | load
       // в кадре: rig.update(time, camera);
  3) Панель (необязательно): createPearceF4Panel(rig).
  4) Слабый Android: шейдерный режим не включать (setShaderMode(false) —
     по умолчанию CPU-путь: MeshBasicMaterial + vertexColors).
  5) Масштаб 1 unit = 1 м, стойки на Y = 0. Габарит модели
     58.0 × 9.4 × 19.3 м при паспортных 58 × 40 × 16 м (лимит-конверт).
     ПЛОСКОСТЕЙ НЕТ: крылья (wing_r/_l, canard_r/_l) убраны по разметке на
     чертеже — силуэт держат корпус, две двигательные балки и горб кабины.
     Кормового «хвоста»-киля тоже нет.
  6) Ориентация: НОС — тупой гранёный форштевень на −X, за ним горб кабины;
     две длинные двигательные балки уходят в КОРМУ (+X), на их кормовых
     срезах — сопла с циановыми решётками. Крылья: две большие кормовые
     лопасти + две средние наклонные плоскости на шарнирах.
  7) Корма СРЕЗАНА между балками: корпус кончается на x ≈ 17.6, дальше
     идут только двигательные балки (до x = 29) — пространство между ними
     ПУСТОЕ, как на чертеже. В кормовом срезе стоит аппарель bay_door_r/_l:
     петля у притолоки (x 17.5), раскрытие 58° — полотно уходит вниз-назад и
     ложится пяткой на палубу (проверено: пятка Y −0.04 м), за срез не
     выходит. Перед аппарелью — грузовой отсек cargo_bay (x 13.2…17.6).
     Створки ракетного отсека на палубе — отдельные узлы bay_lid_r/_l (78°).

Совместимость
-------------
  Имена подвижных узлов (gun_r/gun_l, bay_door_r/bay_door_l, leg_0…leg_2,
  canopy, thrusters, lights, beacon) и четыре режима (pad / flight / hunt /
  load) сохранены — внешний код, который дёргает setMode, продолжит работать.
