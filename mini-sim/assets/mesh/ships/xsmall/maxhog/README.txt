CALICO MAXHOG — управляемые колёса, опытная версия

4 GLB по цветам. +X вперёд, +Y вверх, локальная Z — ось дорожного колеса.
Четыре независимых узла: wheel_front_left, wheel_front_right, wheel_rear_left, wheel_rear_right. Дочерние объекты flame_* — статичные конусы выхлопа.

ВАЖНО: GLB сам по себе не хранит начальную видимость объектов, поэтому при обычном просмотре выхлоп виден даже в дорожном положении. В игре вызывайте createMaxhogControls(gltf.scene) до добавления в сцену: скрипт сразу скроет выхлоп. controls.all(0,false) — дорога, controls.all(1,false) — развёрнутые колёса без тяги, controls.all(1,true) — полёт. controls.wheel('front_left', 0.5, false) задаёт каждое колесо отдельно. См. maxhog-controls.js; подходит для API Three.js r128, но на сайте и Android не тестировался.

Это не готовая анимация и не физическая подвеска: нужно самостоятельно изменять параметр в игровом цикле. Рычаги подвески не двигаются вместе с колёсами; при повороте возможно пересечение с кузовом. Режим полёта приближённый, без настоящего свечения. Из-за раздельных объектов draw calls выше, чем у прежней статичной версии; производительность не измерялась.
