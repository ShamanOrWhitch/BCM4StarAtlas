RAINBOW CHI / PHOTOLI v3 — шейдер перелива + панель управления.

Совместимость с BCM4StarAtlas: ваш mini-sim/assets/js/three.min.js побайтово равен официальному three@0.128.0 (MD5 eb8549863a97355411c3259a3f93b8e1), GLTFLoader отличается только шапкой лицензии, THREE нигде не патчится в других js. Все файлы ниже рассчитаны на этот r128.

СОСТАВ
- rainbow_chi.glb — цельная замкнутая сетка: 1248 вершин, 2492 треугольника, один материал, +Z вперёд, +Y вверх. Внутри только статичная серая форма.
- photoli_shader.js — createPhotoliShader(root): пользовательский ShaderMaterial. Две встречные «жидкие» болотины-полосы, узкий бегущий блик, френелевский перелив, деформация в вершинном шейдере. Нужен GPU, который тянет GLSL; на слабых устройствах возможны фризы.
- photoli_lite.js — createPhotoliLite(root): без ShaderMaterial, только стандартный r128 API. Деформация на CPU (~1248 вершин, ограничение ~13 обновлений/сек), цвет через vertex colors. Рекомендуется для слабых машин.
- photoli_panel.js — createPhotoliPanel(controller): DOM-панель со слайдерами. Одинаково работает с обоими контроллерами (нет метода — слайдер не показывается).
- photoli_demo.html — автономная демка: three r128 + GLTFLoader + модель встроены, переключатель «шейдер/lite», панель управления, вращение мышью/пальцем. Сеть не нужна.
- demo.html — запасная 2D Canvas-демка без WebGL (из lite-версии).
- photoli_controls.js — старая шейдерная версия v2, оставлена для сравнения.

ПАНЕЛЬ (photoli_panel.js)
Форма 0..100% — сила изменения корпуса.
Активность 0..100% — живая пульсация и подсветка бегущих полос.
Цвет 0..360° — фаза перелива (хамелеон).
Перетекание 0..3 — скорость движения полос.
Сила перелива 0..100% — вклад радужного оттенка.
Блик 0..100% — зеркальный блик.

  var rig = createPhotoliShader(gltf.scene); // или createPhotoliLite(...)
  var panel = createPhotoliPanel(rig, { top:12, left:12,
    initial:{ setMorph:.25, setActivity:.3, setIridescence:.7, setGloss:.7 } });
  // в игровом цикле: rig.update(clock.getElapsedTime(), camera);
  // rig.dispose(); panel.destroy();
Методы: setMorph, setActivity, setHue, setFlow, setIridescence, setGloss, update(time, camera), dispose.

ЧЕСТНЫЕ ОГРАНИЧЕНИЯ
Это имитация перелива жидкого металла, не физическое отражение окружения; нормали при деформации не пересчитываются; коллизии и физика форму не повторяют; нет интерьера, прозрачности и настоящего выхлопа; в lite-версии цвет зависит от угла взгляда, а не от среды. В игре, браузере и на Android не проверялось — сначала протестируйте на целевом устройстве, особенно шейдерный режим.
