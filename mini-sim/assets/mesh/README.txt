МОДУЛЬНЫЕ ГОНОЧНЫЕ ТРАССЫ — ПРОТОТИП 01
6 GLB: coast/desert/ice × straight/turn_90. Цвета заданы вершинами; материалы и формы сильно упрощены по сравнению со скетчами, текстур и UV нет. Границы составляют часть одного меша каждого модуля; самостоятельно их редактировать в Blender нужно в Edit Mode.

Геометрия: ширина полотна 2 условных метра, прямая длиной 4, поворот 90 градусов по радиусу 4 по центру. Размер условный: для широких кораблей может понадобиться масштабирование всех элементов или пересборка шире. Верх полотна Y=0 (glTF/Three.js), ось Y вверх. Оси и соединители в manifest.json. Сопоставляйте концы одинаковой позицией, наружные направления должны быть противоположны. Центр поворота НЕ совпадает с концом — для сборки используйте connector position и поворот. Масштабирование меняет размеры соединителей. Поворот создаётся с шагом 3.75°.

Каждый GLB содержит один объединённый меш с цветами вершин; нет физики и коллизий, границы декоративные. Разметка сегментов не гарантированно совпадает на швах, визуальные щели и сопряжение нужно проверить в реальной сцене. Не содержит мостовые опоры, декор, небо и эффекты. GLB не проверен в Blender/Three.js/Android; для r128 требуется совместимый GLTFLoader. PNG — схематический программный рендер с глубиной. Воздушные модули и другие элементы с листов не входят в эту партию.
