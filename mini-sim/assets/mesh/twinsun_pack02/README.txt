TWINSUN — НАБОР ПРОТОТИПОВ 02
8 GLB-файлов: две цветовые версии группы грибов, сундук, пьедестал с кристаллами, кнопка, монета, рунический камень, синее зелье.
PNG — предварительные схематические изображения, не рендер Blender/Three.js. manifest.json — количество треугольников и частей.

Blender: File > Import > glTF 2.0. Части каждой модели сохранены отдельными именованными мешами внутри GLB. Крышка сундука и кнопка — отдельные детали, но анимации и шарниров нет. Варианты грибов имеют одинаковую форму и отличаются цветом.

Детали упрощены; текстурных файлов и UV нет, используются цвета вершин. Свечение, прозрачное стекло, коллизии и анимация не реализованы. Модели пока не проверены в Blender, Three.js r128 и на Android. GLB требует GLTFLoader соответствующей версии r128. Множество отдельных частей может приводить к большому количеству draw calls — требуется измерение и, возможно, объединение геометрии для игры. Это вторая партия, не весь набор из шести референсных листов.
