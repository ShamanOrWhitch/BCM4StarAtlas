# Листы текстур для Tower и Ring (концепты владельца, 19.11.2026)

Референсы, не игровые ассеты: в плагин (`mini-sim/**`) не входят. Плитки для игры вырезаются из них отдельно и сжимаются.

| Файл | Что на листе |
|---|---|
| `textures-grid.webp` | ровная сетка квадратных плиток: красный и серый кирпич (целый и битый), люки, металл, предупредительные полосы, решётки, базальт с лавой, лёд, доски, ящики; внизу ряды платформ на опорах (кирпич, металл, лёд, дерево) |
| `textures-a.webp` | кирпичная башня, круглая площадка со звездой, скала, металл, знак опасности, лёд, лава, доски, огонь, платформы, знамёна, лестницы, трубы, ящики, шипы |
| `textures-b.webp` | кирпич со знаменем, люки, решётки, полосы, лёд, лава, огонь, платформы (бетон, лёд, лава, дерево), лестницы, фонари, трубы, бочки, кристалл, медведи-маски |
| `textures-c.webp` | кирпичная башня, площадки со звездой, кирпичные карнизы, скала, металл, череп-опасность, лёд, лава, огонь, платформы на фермах, вышки, антенны, цветные мишки, шипы, стрелки |
| `pixel-tiles.webp` | пиксельный тайлсет: кирпич, лёд с сосульками, вода, базальт с лавой, доски, камни, цепи, сетки, скелет, слизь, люки, знаки радиации |
| `retro-props.webp` | ретро-реквизит: корабли и станции, книги, медитация, игровые автоматы, брейк-дансеры, музыкальный автомат, пластинки, кассеты, видеосалон, значки |

Второй присланный лист реквизита — тот же файл, что `retro-props.webp`. Автоматы и брейк-дансеры подходят к Opus (картридж, IDEA-021) и Б-бою (IDEA-022).
