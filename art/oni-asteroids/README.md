# Астероиды у сектора ONI CSS (листы владельца, 20.11.2026)

Референсы, не игровые ассеты: в плагин не входят. Плитки для игры вырезаются отдельно (как `tools/ring-tiles/cut.mjs`).

| Файл | Что на листе |
|---|---|
| `oni-asteroids-a.webp` | крупные глыбы с граффити (медведь, звезда, полосы красный/жёлтый/зелёный), друзы кристаллов, светящиеся грибы; ряд плиток пористого камня, мха, кристаллов, грибов; значки-трафареты; мелкие камни и обломки |
| `oni-asteroids-b.webp` | то же в тёмной гамме: глыбы с граффити, плитки поверхности, значки, мелкие камни, кристаллы и грибы по отдельности |
| `oni-asteroids-c.webp` | граффити-глыбы (медведи в шлеме, звёзды), глыбы с кристаллами и грибами, голые камни разной породы, сетка плиток камня, наклейки |
| `oni-asteroids-d.webp` | глыбы с граффити и наростами, мелкие камни, плитки камня с цветными прожилками, трафареты, когти-царапины |
| `oni-asteroids-tiles.webp` | квадратные плиты астероидной поверхности с граффити, кристаллами и грибами; трафареты медведей и звёзд; россыпь камней, кристаллов и грибов |

Второй присланный лист «b» — дубль. Для Warp (поле астероидов), лабиринта астероида и клеток Ring у ONI CSS.
