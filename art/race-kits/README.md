# Листы реквизита трасс (концепты владельца, 19.11.2026)

Двухмерные листы-концепты для декораций Shoal Race по планетам. Это референсы, не игровые ассеты: в плагин (`mini-sim/**`) не входят, в пакет сайта не попадают. Игровые модели (GLB) по ним — работа Др Арены.

| Файл | Тема | Что на листе |
|---|---|---|
| `coast.webp` | Морской берег | асфальт с бортами, мосты на сваях, маяк, причалы, пальмы, скалы, буи, чайки, волны, финишная арка |
| `desert.webp` | Пустыня | песчаная дорога с камнями, арки, обелиски, пирамиды, оазисы, кактусы, караван, флаги, пыльные вихри |
| `ice.webp` | Лёд | ледяная дорога и мосты, кристаллы, иглу, ели в снегу, пещеры, пингвины, сияние, ледяная арка |
| `lava.webp` | Лава | базальтовая дорога с трещинами лавы, шипы, дымящие жерла, мёртвые деревья, золотые кристаллы, врата |
| `jungle.webp` | Джунгли | грунтовые трамплины, верёвочные мосты, лианы, водопады, руины, грязь, обезьяны, цветочная арка |
| `sky.webp` | Небо | дороги на облаках, радуги, хрустальные площадки, дирижабли, летающие острова, кольца, порталы, крылатая арка |

Второй присланный лист «берег» — тот же файл, что `coast.webp`.
